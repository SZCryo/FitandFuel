# LFT-01

Title: Repo bootstrap and branch protections

Owner: Edgar A.
Branch: `feature/LFT-01-repo-bootstrap`

## Goal

Get the project under source control with a stable main branch and a simple pull request workflow.

## Scope

- Initialize the repo and push the base structure
- Set `main` as the working branch
- Add `.gitignore`
- Set pull request review as the default merge path

## Acceptance

- Repo exists on GitHub
- `main` is active
- Pull request workflow is documented
- Team can branch from the same base
